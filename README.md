Interactive Dashboard (Base Version)
This repository contains an Excel-based Interactive Dashboard designed for data visualization and basic analytics. It provides a user-friendly interface with dynamic elements to help users explore and analyze data interactively.

📊 Features
Interactive slicers and drop-down filters

Dynamic charts and graphs (bar, pie, line)

Summary metrics 

Clean and professional layout

Excel-based – no need for additional software

📁 File Included
Interactive_Dashboard_Base Main.xlsx – The main Excel file containing the dashboard.

🚀 How to Use
Download or clone the repository.

Open the Interactive_Dashboard_Base Main.xlsx file in Microsoft Excel (recommended: Office 2016 or later).

Use the slicers and filters to explore the data and update charts in real-time.

🛠️ Customization
Replace the sample dataset with your own data by following the existing format.

Adjust formulas, charts, and slicers as needed to suit your needs.

📌 Requirements
Microsoft Excel (2016 or newer recommended)
